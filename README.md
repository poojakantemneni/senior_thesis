# senior_thesis
This contains the code I used for my senior thesis on gendered agricultural production in Mali.
DATCONS_main_household_AND_main_member_raw.do merges the main member-level and main household-level datasets.
VARCONS_indices_MB_ROUND_raw.do creates indices and merges these new variables into the merged household and member dataset.
DATCONS_mb_plots_raw_final.do merges the household and member dataset with the main plot-level dataset.
4.23.26_AllPotentialConsiderations.do contains my code for data counts, baseline statistics, and every potential specification I could include in the paper. 4.24.26_AllExports.do contains the code I used to export everything.
The datasets are not publicly available. Email me (poojakantemneni2026@u.northwestern.edu) if you need to access them.
